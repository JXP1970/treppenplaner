# Changelog

## 1.1.0
- Mahlzeiten werden per Lebensmittel + Menge (g) erfasst; Kalorien werden automatisch aus einer eingebauten Datenbank (~60 Lebensmittel) berechnet, inkl. Autocomplete und manuellem Fallback für unbekannte Lebensmittel.

## 1.0.0
- Erste Version: BMR/TDEE-Berechnung (Mifflin-St-Jeor), Kalorienziel je nach Ziel (Abnehmen/Halten/Zunehmen), Makro-Aufteilung, sowie ein Tages-Tracker mit manueller Kalorieneingabe (localStorage).
